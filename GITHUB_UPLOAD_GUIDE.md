# GitHub Upload Guide

1. Extract the ZIP.
2. Rename the extracted folder to `logistics-data-analytics` if needed.
3. Create a new GitHub repository named `logistics-data-analytics`.
4. Keep the repository public if your internship requires the evaluator to access it.
5. From the project folder, run:

```bash
git init
git add .
git commit -m "Complete logistics analytics internship Weeks 1-4"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/logistics-data-analytics.git
git push -u origin main
```

6. Your submission URL will be:

`https://github.com/YOUR-USERNAME/logistics-data-analytics`

Do not commit passwords, API keys, private company data, or confidential files.
