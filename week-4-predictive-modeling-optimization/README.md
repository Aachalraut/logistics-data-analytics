# Week 4 – Predictive Modeling and Optimization

This week focuses on predictive modeling and optimization for logistics operations.

## Main Activities

- Define the prediction problem
- Prepare features and target variable
- Train and test machine learning models
- Compare Linear Regression, Random Forest, and Gradient Boosting
- Evaluate models using MAE, RMSE, and R²
- Perform cross-validation
- Apply hyperparameter tuning
- Develop an illustrative logistics optimization scenario
- Analyze resource allocation and delivery-time improvement
- Generate actionable recommendations

## Model

The target variable is delivery time in hours.

## Optimization

The optimization scenario evaluates a potential transportation-mode reassignment for selected shipments.
