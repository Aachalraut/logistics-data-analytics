# Week 1 — Strategic Planning and Data Exploration

## Objective

This task establishes the planning and strategy phase of a logistics data-analysis project.

## Scenario

FastMove Logistics is a hypothetical e-commerce logistics company operating regional warehouses and last-mile delivery.

The strategic questions are:

- Which delivery areas and routes experience the most delays?
- How can future delivery times and order demand be predicted?
- Which delivery locations have similar operational characteristics?
- How should vehicles, drivers, inventory, and delivery capacity be allocated?

## KPIs

- On-Time Delivery Rate
- Average Delivery Time
- Order Fulfillment Rate
- Stockout Rate
- Vehicle Utilization
- Average Route Distance

## Proposed Data Science Methods

- Exploratory Data Analysis
- Regression
- Classification
- Demand forecasting
- K-Means clustering
- Vehicle Routing Problem/resource optimization
